# Obsidian Vault Daily Activity Sync

Automate the synchronization of daily activity summaries to the Obsidian vault.

At the end of daily activity (6 PM local time daily), automatically land a Gemini synthesized human-friendly readable summary into the Obsidian vault within `0. Today's Notes`.

Note: A system script already copies these notes every day into `0. Yesterday` so `0. Today's Notes` gets cleared out.
