## Why

The dashboard is the daily-driver surface for this whole system, and it currently
undercuts its own signal. Four time formats on one screen means the operator has to
re-parse the visual language per card instead of scanning. `19d ago` with no absolute
date is unanchored — it silently ages every time the page is regenerated, and a stale
render is indistinguishable from a fresh one. `(42d old)` welded into a reminder's
title string is worse: it corrupts the *data* field with presentation, so the title is
no longer usable anywhere else.

The structural cause is that there is no shared row abstraction. `web_components.py`
provides a shared *shell* (tokens, chrome, sidebar), but every list in the Today view
hand-rolls its markup and gets its own CSS block inside a single ~730-line `PAGE_CSS`
literal. Each new module has therefore drifted a little further from the last. Adding
the two missing primitives is what stops the drift recurring — the per-module fixes in
Phase 3 are the visible payoff, but Phases 1–2 are the part that lasts.

## Key concepts

- **`format_timestamp` extends, not replaces, `tz_utils`.** GH-130 already centralized
  UTC→local display into `src/rebalance/tz_utils.py` (`local_tz`, `to_local`,
  `parse_utc_iso`, `format_local`, `format_relative`) and shipped it through a Codex
  relay review with DST-boundary regression tests. The new helper **composes** those.
  Introducing a second time module would re-open exactly the fragmentation GH-130 closed.
- **Absolute is the anchor; relative is a suffix.** `2026-07-17 8:02 PM · 2h ago`.
  A relative time never appears alone.
- **`web/pulse.html` is a build artifact.** It is generated by `scripts/pulse_web.py`
  and re-written by the scheduler (`scripts/install_pulse_web_scheduler.sh`). Editing it
  directly is silently discarded.
- **Presentation only.** No data source, route, API handler, or collector changes.

## Phase 1 — shared timestamp helper

- [ ] Add `format_timestamp(value, *, relative: bool = False, tz=None) -> str` to
      `src/rebalance/tz_utils.py`, implemented **on top of** the existing
      `format_local` / `format_relative` / `parse_utc_iso`. Absolute form
      `%Y-%m-%d %-I:%M %p` → `2026-07-17 8:02 PM`; with `relative=True`, append
      ` · {format_relative(...)}`. Returns `""` on unparseable input, matching the
      existing `format_local` contract so callers keep choosing their own fallback.
- [ ] Add the render-side treatment: monospace (`ui-monospace` stack), tabular numerals,
      muted color, as a single CSS class applied by the shared row (Phase 2), not
      re-declared per module.
- [ ] Migrate all 13 `_ago()` call sites, `_format_dt`, and `_format_dt_short` onto it.
      Delete `_format_dt` / `_format_dt_short` once call sites are zero.
- [ ] Unit tests: absolute-only, absolute+relative suffix, unparseable → `""`, and a
      DST-boundary case (mirroring the GH-130 regression suite's approach).

## Phase 2 — shared row component

- [ ] Extract a `data_row(...)` renderer (naming to match this codebase's existing
      `render_*` / `_render_*` convention) with a fixed anatomy, in order:
      1. Leading marker, fixed width — checkbox / type badge / rank / avatar-letter.
      2. Body — **title first** (medium weight), then one meta line below (person · chips).
      3. Trailing — right-aligned timestamp block (`format_timestamp` output).
- [ ] Zebra striping: alternate rows get a ~3% ink background tint, driven by the shared
      component, not per-module CSS.
- [ ] Adopt it in: Reminders sidebar, Recent GitHub activity, Recent Figma comments,
      What's Next, Recently Completed, and all three Today's Goals columns.
- [ ] Retire the per-module row CSS blocks the component subsumes.

## Phase 3 — per-module fixes

- [ ] **Reminders (sidebar)** — title first, then `person`, then `due <timestamp>`.
      Replace `A.)`-style text prefixes with a compact letter-keycap badge. Remove the
      age string from the title; render it as a structured `age` chip.
- [ ] **Recent GitHub activity** — replace unlabeled glyphs (`+ ○ ↑ ●`) with small
      labeled type badges (Issue / PR / Comment / Commit) in distinct colors. Strip the
      org prefix from repo names (`Claude-AI-Tools-Ventura-County/xyz-3-agents-swarm` →
      `xyz-3-agents-swarm`), full path in the `title` attribute.
- [ ] **Recent Figma comments** — author top-left, timestamp top-right, comment body
      below, file link last. Remove raw thread IDs (`VoQWc0fh0020JoxOyqeE1P`) from the
      UI. Sort strictly newest-first.
- [ ] **What's Next** — center the rank circle against the first text line. Show the
      top 3 ranked items, not 1; move the count into the link
      ("Open What's Next → 21 ranked").
- [ ] **Today's Goals** — the three columns use identical row styling (same checkbox,
      padding, zebra). Remove the divider rules that exist only in column 1. Every Apple
      Reminder with a date gets the shared right-aligned timestamp, not just the first.
- [ ] **Recently Completed** — use the shared row (check-glyph marker, struck-through
      title, timestamp, Undo as a quiet outline button) instead of the bordered-card
      pattern. Keep the client-side JS re-render path (`:2170-2190`) in sync.
- [ ] **Progress header** — `0 done · 9 in progress` beside a 0% bar is contradictory.
      Compute the bar from done/total and drop the redundant `0%` label.

## Phase 4 — section header casing

- [ ] Card titles in sentence case: "Today's goals", "What's next", "Recent GitHub activity".
- [ ] Sub-section labels in 11px uppercase, letter-spaced, with counts applied
      consistently: `GOALS · 3`, `NEXT OPEN TODOS · 6`, `RECENTLY COMPLETED · 3`.

## Anti-goals

- No data-source, collector, route, or API-handler changes. If a fix appears to need
  one, stop and flag it rather than widening scope.
- No new time module. `tz_utils.py` is the single source of truth (GH-130).
- No hand-edits to `web/pulse.html` — it is regenerated and would be silently clobbered.
- No JS framework introduction. The page stays server-rendered strings + vanilla JS.
- No behavioral change to the goal-complete / reminder-complete POST handlers.

## Open design calls

1. **Where the shared row CSS lands.** `web_components.py` is shared with the
   live-rendered Focus 5 / What's Next / Auth Log pages (`src/rebalance/web.py:380`),
   which would then inherit the new row styling — arguably correct, since the drift
   this issue fixes will otherwise recur on those surfaces too, but it widens the blast
   radius beyond the Today view. Page-local in `PAGE_CSS` is the narrow, reversible
   option. **Recommendation:** land the component in `web_components.py` but adopt it
   only on the Today view in this pass, leaving the other pages to opt in later.
2. **Whether `_ago()` in `scripts/dashboard.py` also migrates.** It is shared with the
   TUI (`dashboard.py:840, :993`), which has different formatting constraints. Default
   is to leave the TUI call sites alone and migrate only the web page's 13.
