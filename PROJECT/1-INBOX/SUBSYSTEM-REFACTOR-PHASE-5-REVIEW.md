### Ranked Findings

1. **[High] Provenance is dropped during push sync.** In `src/rebalance/ingest/registry.py:_push_from_projection`, `external` is correctly popped from `custom_fields`, but `provenance` is completely ignored during `Project` instantiation. As a result, running `rebalance ingest sync --mode push` wipes `Project.provenance` from the top level, degrading downstream context.
2. **[Medium] `PROJECT_LIFECYCLE` is dead code.** Over-engineering check #7: `PROJECT_LIFECYCLE` is defined in `lifecycle.py` and extensively verified by `test_lifecycle_contract.py`, but it is **not consumed by a single runtime function in the entire codebase**. `onboarding_status` and the CLI exclusively consume `SETUP_STAGES`. It is effectively documentation disguised as an array.
3. **[Low] Incomplete normalization merge.** While string scrubbing (`normalize_match_text`) is unified, chunking logic is still duplicated. Inference uses `_split_tokens` (which replaces periods and strictly lowercases) while the classifier uses `_camel_case_parts` (which preserves casing to extract acronyms). 
4. **[Low] Semantic tests check strings, not bounds.** The contract test suite ensures `PROJECT_LIFECYCLE` contains the string `"read_only"`, but only end-to-end tests provide actual enforcement. There is no automated lock verifying that prioritization (`read_time_overlay`) doesn't secretly persist to DB.

### Overall Verdict

The Phase 5 subsystem refactor cleanly isolates the read/write paths and delivers on its core promise of enforcing an operator-first boundary. Discovery is successfully isolated as a pure read path, and curated SQLite rows are structurally shielded from inference overwrites. However, the implementation is slightly marred by a `provenance` data loss bug in the `sync_registry(mode="push")` projection logic, and `PROJECT_LIFECYCLE` exists strictly as unconsumed, over-engineered declarative baggage. Aside from fixing the `provenance` pipeline leak, there are no structural roadblocks to building the Phase 6 `/welcome` agent on top of this foundation.
