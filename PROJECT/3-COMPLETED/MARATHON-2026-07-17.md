## Firing (harness — not a manual tick seed)

This runs through the `marathon.sh` harness, which seeds its own per-phase tick tokens
(`MARATHON-P1-TURN` … `MARATHON-P4-TURN`) — do not hand-seed a task for it.

```bash
.xyz/relay-automation/marathon.sh \
  --plan PROJECT/2-WORKING/GH-135-PULSE-DASHBOARD-CONSISTENCY/MARATHON.yaml
```

Builder is `codex` (the harness default — bills via the Codex/ChatGPT subscription, not
per-call API); reviewer is `agy` on every phase, since the harness requires builder and
reviewer to be different agent ids. Add `--dry-run` to re-validate the plan without
running it; `--retry <phase-id>` recovers a phase whose relay task was left unclaimed.
