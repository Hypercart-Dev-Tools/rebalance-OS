Real concurrent (same-wall-clock) execution across lanes would need `relay-drive.sh`'s per-harness
driver lock either bypassed (raw `tick take`/`done` loops, no supervisor — the `MARATHON-QUEUE`
precedent) or a second vendored `.xyz` harness. Today's run drives all 3 lanes through
`relay-xyz` (`relay-drive.sh` + `codex-turn.sh`/`agy-turn.sh`, Producer=codex / Reviewer=agy,
`--target-root` pinned to the true repo toplevel per the GH-113 lesson) **sequentially** — same
full build+review rigor per lane as the Focus5Float hide button, just not wall-clock-parallel. The
path-disjointness above is what makes a *future* genuinely concurrent run safe, not a claim that
today's run is concurrent.
