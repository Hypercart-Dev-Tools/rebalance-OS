## Why one lane, not an XYZ queue

Unlike the archived MARATHON queues, GH-112 is **not path-disjoint**:

- **Phase 1 and Phase 2 edit the same file.** P2's post-midnight skip is a ~5-line guard at the top of P1's entrypoint. You cannot lane-split them; they are one unit — build them together.
- **Phase 3 is downstream, not parallel.** The bash wrapper + launchd plist must invoke P1's final module path + CLI args, so they block on P1's interface being settled.
- **Effort-2 task.** The only "legal" split (core module ‖ wrapper+plist+docs) buys ~20 min against real coordination overhead — a low-ROI parallelization. Run sequential.
